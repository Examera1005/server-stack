# Contributing to Server Stack 🚀

Thank you for considering contributing to **Server Stack**! We welcome improvements, bug fixes, documentation updates, and new service integration suggestions.

## 🤝 How to Contribute

1. **Fork the Repository** to your own GitHub account.
2. **Create a Feature Branch** (`git checkout -b feature/awesome-feature` or `fix/issue-fix`).
3. **Commit your Changes** with clear commit messages (`git commit -m 'feat: add jellyseerr service to media stack'`).
4. **Push to the Branch** (`git push origin feature/awesome-feature`).
5. **Open a Pull Request** explaining your changes and motivation.

## ⚠️ Important Rules for Pull Requests

- **No Secrets or Credentials**: Never commit API keys, `.env` files with real credentials, database files (`*.db`), or private tokens (`.arl`).
- **Clean Configuration Templates**: Always use `.env.example` templates for configuration files.
- **Maintain Modular Architecture**: Keep stack components inside their respective subdirectories (`immich/`, `media/`, `music/`).
- **Update Documentation**: If you add or modify a service or port, update both `README.md` and `README.fr.md`.

Thank you for helping build a better self-hosted experience!
